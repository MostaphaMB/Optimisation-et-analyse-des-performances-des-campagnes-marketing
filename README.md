## 📝 Description du Projet
Ce projet consiste à mesurer et visualiser l'impact des campagnes marketing sur les ventes et le comportement des clients. En tant que Data Analyst, l'objectif est de transformer un dataset complexe (données démographiques, transactions, campagnes) en un outil décisionnel interactif permettant d'identifier les leviers de croissance et les produits les plus performants.

## 🎯 Objectifs du Projet
* **Analyse Exploratoire (EDA)** : Comprendre la structure du dataset et identifier les segments clients.
* **Validation Statistique** : Effectuer des tests d'hypothèses pour mesurer l'impact réel des campagnes sur les ventes.
* **Ingénierie des Données** : Nettoyer et transformer les données via Power Query pour une analyse fluide.
* **Modélisation & BI** : Créer un modèle de données robuste et un dashboard interactif sous Power BI.

## 🛠️ Stack Technique
* **Python** : `pandas`, `numpy` pour le traitement ; `scipy`, `statsmodels` pour les tests statistiques.
* **Visualisation Python** : `matplotlib`, `seaborn`, `plotly`.
* **Power BI Desktop** : Power Query, Modélisation et DAX.
* **Gestion de version** : Git & GitHub.

## 🚀 Étapes de Réalisation

### 1. Analyse Exploratoire & Statistiques (Python) 🐍
* Identification des types de variables (continues vs discrètes).
* Analyse descriptive et détection des valeurs aberrantes.
* Réalisation de tests statistiques pour confirmer les relations entre les campagnes et le comportement d'achat.

### 2. Transformation et Modélisation (Power BI) ⚙️
* Importation et nettoyage des données (`data.csv` et `dictionnaire.csv`) dans Power Query.
* Mise en place d'une modélisation de données optimale pour l'analyse des ventes.
* Création de mesures DAX pour suivre la performance des campagnes.

### 3. Dashboard Interactif & Insights 📊
* **Analyse des Ventes** : Répartition par produit et par campagne (Stacked bar charts).
* **Canaux d'Achat** : Visualisation de la répartition par plateforme (Web, Catalogue, Magasin).
* **Expérience Utilisateur** : Intégration de filtres et segments pour une exploration dynamique des données.
* **Recommandations** : Formulation d'insights actionnables basés sur les résultats observés.

## 📦 Contenu du Dépôt
* `Exploration_Marketing.ipynb` : Notebook Python contenant l'EDA et les tests statistiques.
* `Campaign_Analysis_Dashboard.pbix` : Rapport Power BI interactif.
* `data/` : Dossier contenant les datasets sources.
